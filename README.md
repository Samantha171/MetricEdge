# MetricEdge – Financial Performance Analysis Dashboard

MetricEdge is an ongoing financial analytics project that analyzes multi-year financial performance of major companies using Python and Power BI.

##  Project Overview
- Automated extraction of income statement and balance sheet data using the Alpha Vantage API
- Cleaned and structured financial data for analysis-ready reporting
- Interactive Power BI dashboard for cross-company and year-wise comparison

##  Key Metrics & KPIs
- Revenue & Net Income Trends
- Profit Margin %
- Current Ratio
- Debt-to-Equity Ratio
- ROE & ROA (derived)

##  Tech Stack
- Python (Requests, Pandas)
- Alpha Vantage API
- Power BI (DAX, interactive visuals)

##  Repository Structure
- `main.py` – API data extraction and preprocessing
- `financials_powerbi.csv` – cleaned dataset
- `project.pbix` – Power BI dashboard
- `README.md` – project documentation

##  Project Status
Ongoing – currently enhancing insights automation and exploring forecasting techniques.
